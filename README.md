# OrangeHRM Automation Project
This project automates critical flows of the OrangeHRM Demo Application using Selenium, PyTest, and the Page Object Model (POM) design pattern.

# Features Automated:
1. Login Flow
2. Navigate to PIM Module
3. Add 3–4 Employees
4. Verify Employees in the Employee List
5. Log Out from Dashboard


# Technologies Used
1. Python 3.x
2. Selenium WebDriver
3. PyTest
4. Page Object Model (POM)

# How to Run
1. Clone the repository
git clone https://github.com/bhardwaj-commits/orange-hrm-automation.git
cd orange-hrm-automation

2. Install dependencies
pip install -r requirements.txt

3. Run the test
pytest tests/test_full_workflow.py
